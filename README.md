# GameBoost - compilar APK con GitHub

1. Crea un repositorio nuevo en github.com y sube TODO el contenido de esta carpeta
   (incluida la carpeta oculta .github).
2. Ve a la pestana Actions > "Build APK" > Run workflow (o se lanza solo al subir a main).
3. Cuando termine (3-6 min), entra en la ejecucion y descarga "GameBoost-APK" en Artifacts.
4. Descomprime el zip, pasa app-debug.apk al movil e instalalo.
5. En la app da los permisos "Overlay" y "No molestar".
